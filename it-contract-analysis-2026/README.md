# 2025 → 2026 IT 용역 계약 변경사항 분석 (경영진 보고용)

`IT용역계약_2026_분석보고.pptx` — 30슬라이드, 현황 분석 → 문제점 진단(8건) → 개선 방법론 → 부록 구성.

## 재생성 방법
```
pip install python-pptx
python3 generate_ppt.py
```
`generate_ppt.py` 실행 시 같은 폴더에 `IT용역계약_2026_분석보고.pptx`가 재생성됩니다.
숫자를 갱신하려면 스크립트 상단부 각 섹션의 데이터 리스트(예: `c25`, `c26`, `rows13` 등)를 수정하세요.

## 데이터 출처
- 원본: 그룹사 계약 data(Excel), A3:U1108 (1,106행 × 21열)
- 슬라이드 내 모든 수치는 사용자가 제공한 요약 분석 결과를 그대로 반영했습니다. 원본 Excel 파일 자체는 이 저장소에 포함되어 있지 않습니다.

## 참고 사항 (구성상 판단)
- 원 요청안의 "대분류별 분석"(슬라이드 10)은 제공된 데이터에 세부 수치가 없어, 동일 데이터 기반인 "도입구분별 분석(기존 vs 신규)"과 통합해 슬라이드 10에서 표+도넛차트로 다루었습니다.
- 슬라이드 28의 "고비용 세부 항목"은 본문에서 실제로 언급된 항목들 중 비용이 명시된 것만 선별한 것으로, 전체 데이터 기준 공식 Top 10 순위가 아닙니다(원본 Excel 재조회 필요).
