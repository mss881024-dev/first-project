# 컨소시엄 회의록 (2차) — 동아그룹 4개사 Microsoft EA·SCE 갱신 제안서 리뉴얼

| 항목 | 내용 |
|------|------|
| 일시 | 2026-07-09 (2차 회의) |
| 안건 | ① 기존 제안서 디자인 전면 개편 ② SCE(서버) 라이선스 데이터 추가 반영 ③ 계약기간 변경 |
| 배경 | 고객 피드백: 기존 디자인 불만족, SCE 라이선스 누락, 계약기간 2026.03.31~2028.04.01로 변경 |

## 1. 컨소시엄 편성 (실제 서브에이전트 소환)

| 역할 | 수행 내용 |
|------|-----------|
| 오케스트라 PM (본 세션) | 총괄, 데이터 검증, 디자인 방향 결정, 최종 구현·QA |
| 디자이너 A (에이전트) | "모던 클린" 시안 — 기존 디자인 문제점 5개 + 신규 스펙 제안 |
| 디자이너 B (에이전트) | "이그제큐티브/컨설팅 리포트" 시안 — 액션 타이틀 체계 제안 |
| PPT 구성 설계 (에이전트) | 15장 스토리보드 — 깔때기 구조(결론 선행 → 요약 → 상세 → 분석) |

## 2. 디자이너 의견 수렴 결과

**공통 지적 (양측 일치)**
- 꽉 찬 네이비 헤더바·전면 네이비 표지가 무겁고 올드함 (90년대 SI 제안서 인상)
- 네이비 채움 표 헤더 + 전체 세로선이 숫자 비교를 방해
- 오렌지/컬러 강조 남발로 시선 우선순위 붕괴
- 박스 중첩 과다, 여백 부족

**디자이너 A (모던 클린)**: 흰 배경 + 가는 라인 + 오렌지 1포인트, 라운드 KPI 카드, 화이트 표지
**디자이너 B (컨설팅 리포트)**: 액션 타이틀(제목=결론 한 문장), 헤어라인 표, 빅넘버 스탯 밴드, 페이지 트래커, 모노톤+틸 1색

## 3. PM 결정 사항 — 하이브리드 채택

1. **레이아웃 문법**: 디자이너 공통안 — 네이비 면 채움 전면 폐기, 흰 배경 + 헤어라인 + 여백
2. **팔레트**: 디자이너 A안 채택 — 네이비 잉크(#1B2A4A) + 오렌지(#E86C1A) 단일 액센트 (틸 전환은 브랜드 연속성 저하로 기각)
3. **타이틀 체계**: 디자이너 B안 채택 — 전 슬라이드 액션 타이틀 (예: "증가액 1.12억 원은 전액 인원 증가분 — 단가 인상 요인은 0원입니다")
4. **표 스타일**: 디자이너 B안 — 세로선·채움 제거, 상단 1.5pt/헤더 하단 0.75pt 네이비 라인 + 0.5pt 헤어라인, 합계행만 옅은 채움
5. **숫자 강조**: 빅넘버 스탯 밴드 (슬라이드당 최대 3개, 강조색 슬라이드당 1~2곳 원칙)
6. **구성**: 설계 에이전트 15장 안 → 14장 압축 (계약구조+갱신전략 통합, 워터폴 차트 → 표+스탯 대체)

## 4. 신규 데이터 검증 (PM)

- SCE 5개 품목 × 4사 소계, EA+SCE 회사별 합계, 전체 총계 전 항목 검산 **일치**
- **검증 노트**: 에스티젠바이오 SCE 5개 품목 합산 시 28,834,201원으로 제시 소계(28,834,200원)와 **1원 차이** (원 단위 절사 추정). 4사 SCE 합계·전체 총계도 동일하게 1원 차이. → **고객 제시 소계·총계 금액을 기준으로 표기**하기로 결정.
- 계약기간 2026.03.31 ~ 2028.04.01로 전 슬라이드 갱신. 이전 버전의 단가(390,600원 등)는 신규 요청에 미포함이므로 제안서에서 제외.

## 5. 산출물 구성 (14장)

표지 → 목차 → ①제안 개요(스탯 밴드) → ②계약 구조·갱신 원칙 → ③4사 총계 비교 → ④EA 요약 → ⑤SCE 요약(전 품목 동결 매트릭스) → ⑥~⑨회사별 상세(EA 상단/SCE 하단/좌측 요약 카드) → ⑩증감 요인 분석 → ⑪계약 조건·일정 → 맺음말

## 6. (3차 개정) 기타 라이선스 추가 반영 — v3

- 고객 추가 데이터: **기타 라이선스**(Copilot·Teams Pro·Easy Tree) 4사분 수신 → 15페이지로 재구성
- 스토리 변경: 총계 기준 +9.3% → **+3.9%** (True-up +111.7백만 원을 기타 최적화 -62.8백만 원으로 상쇄)
- 신규 슬라이드: 기타 라이선스 요약(-88%), 회사별 페이지에 기타 표 추가, 증감 분석에 절감 구성 반영
- **검증 노트 (v3)**
  - 동아쏘시오홀딩스 전체계(70,779,400 / 42,631,000원)는 구성 항목 합산보다 **각 42원 작음** — 단수 조정으로 추정되나 원본 표에는 단수조정 행이 없음 (동아에스티만 -2,260/-4,860원 명시). 제시된 전체계 금액 기준으로 표기.
  - 원본 요청 하단 "계약 정보: 2024.03.31~2027.04.01"은 상단 명시 계약기간(2026.03.31~2028.04.01)과 불일치 → **상단 기준 적용**.
  - 그 외 전 항목 검산 일치 (기타 합계 71,164,800→8,404,200원 / 4사 총계 1,267,881,200→1,316,794,600원, +3.9%).

## 7. 전수 계수 검증 (4차, PM)

사용자 요청으로 전체 수치를 처음부터 재검산. 검증 범위: EA 소계(Renewal+True-up), SCE 소계(5품목 합산), 기타 소계(Copilot/Easy Tree/Teams Pro 합산), 회사별 전체계(EA+SCE+기타), 4사 총계, 전 슬라이드 표기 증감률(%), 스크립트에 하드코딩된 모든 금액 리터럴(정답셋 대조).

**결과: 금액·증감률 전 항목 일치.** 기존에 파악한 2건(쏘시오 단수 42원차, 계약기간 표기 불일치)을 재확인했고, 4사 합산 단수조정(-2,302/-4,902)이 실제로 쏘시오(-42/-42)+에스티(-2,260/-4,860) 정확한 합임을 추가 확인 — 표기 오류 아님.

**신규 발견·수정 사항 1건**: PPT 08번 슬라이드(기타 라이선스 요약)와 13번 슬라이드(증감 요인 분석)에 "Copilot 105 → 15 Copy"라고 서술했으나, 원본 데이터에는 에스티(42→9)·제약(30→6)·에스티젠(10→0) 3사의 Copy 수만 있고 **쏘시오홀딩스의 Copy 수는 원본에 없음**. 단가 역산(516,600원/Copy 기준)으로 쏘시오 25Y가 24 Copy로 추정되어 합계가 106이 되지만, 이는 PM이 임의 추정한 값으로 원본 미제공 수치를 제안서에 사실처럼 기재하는 것은 부적절 → **"3사 82→15 Copy 재산정, 쏘시오는 갱신 종료"로 수정**(쏘시오는 Copy 수 대신 갱신 종료 사실만 기술).

## 8. 문구 리스크 검토 (5차, 사용자 피드백)

사용자 지적: "에스티젠바이오 +33.7% — 사업 확장(+130EA)이 만든 성장의 지표입니다"라는 슬라이드 제목이 **리스크 있음** — 33.7% 비용 증가를 벤더가 "성장의 지표"라며 고객에게 어떻게 받아들여야 할지 규정하는 것처럼 읽혀, 비용 증액 통보에 대한 반감을 살 수 있음.

동일 패턴을 전체 스캔해 3곳 수정:
- 에스티젠바이오 상세 페이지 제목: "성장의 지표입니다" → **"증가분은 전액 True-up 130EA(사용자 순증)에서 발생했습니다"** (다른 3개사 제목과 동일하게 사실 서술형으로 통일)
- 4사 총계 비교 제목: "성장 투자(에스티젠·에스티)" → **"사용자 증가(에스티젠·에스티)"** (투자라는 긍정적 프레이밍 제거)
- 기타 라이선스 요약 스탯 밴드: "성장 재원" → **"56% 상쇄"** (절감액이 True-up 증가분의 56%를 상쇄한다는 사실만 표기)

원본 데이터에 명시된 사업 확장 관련 서술(배지·노트의 "사업 확장 반영" 등)은 고객이 제공한 사유를 그대로 인용한 것이라 유지. 벤더가 독자적으로 "이건 좋은 신호"라고 평가하는 표현만 제거.

## 9. 계약기간 정정 (6차, 사용자 확정)

사용자 확인: 계약기간은 **2024.03.31 ~ 2027.04.01**이 맞음 (v3 요청 하단 "계약 정보"가 정확했고, 상단 표기가 오기재였음 — 4차 검증 노트에서 반대로 추정했던 것을 정정).

- 표지·계약 개요·계약 조건 표·STEP 3 등 전 슬라이드의 계약기간 표기를 2024.03.31~2027.04.01로 일괄 수정
- **부수 이슈 발견**: 계약기간이 3년(2024→2027)으로 확정되며 "3년 차 갱신" 라벨과 일관성이 맞음(기존 2026→2028 표기는 실제로는 2년+1일이라 "3년 차"와 모순이었음, 이번 정정으로 해소)
- STEP 3 "계약 체결 (2024.03.31 발효)"는 이미 지난 날짜를 향후 일정으로 표시하는 오류였음 → 사용자 확인 후 **"3년 차(26Y) 갱신 물량 확정"**으로 수정 (신규 계약 체결이 아니라 기존 3년 계약의 3년 차 True-up 확정 단계임을 반영), STEP 4도 "확정분 반영 및 연중 True-up 관리 지원"으로 조정

## 10. 톤 전면 재검토 (7차, 사용자 피드백)

**계기**: 7페이지(SCE 요약) 하단 스탯 "비용 안정성 — 3년 약정 동결"이 문제로 지적됨 — 서버 수량이 애초에 늘지 않아 자연히 0%인 것을, 마치 벤더가 협상으로 지켜낸 성과처럼 표현했음. 사용자가 이어서 "이게 비즈니스상 갱신을 제안하는 문서인데 이런 식의 표현이 맞냐"고 전체 톤에 대한 근본적 문제 제기.

**PM 판단**: 타당한 지적. "액션 타이틀(제목이 결론/해석을 말하게 하라)"는 컨설팅 PT 기법을 그대로 적용하면서, 사실을 전달하는 것을 넘어 벤더가 "이건 좋은 신호다/우리가 지켜낸 성과다"라며 고객이 느껴야 할 감정과 해석까지 규정하는 표현이 여러 곳에 스며들었음. 이 문서는 고객사 내부 결재선이 비용 증액 여부를 판단하는 근거 자료이므로, 판단을 도와주는 대신 벤더가 판단을 대신 내리는 톤은 신뢰도를 해칠 수 있음.

**수정 범위: 전체 재검토** (사용자 선택). 액션 동사(상쇄했다/방어했다/균형을 이룬다/관리한다 등 벤더의 능동적 성과·해석을 주장하는 표현)를 팩트 서술(수동태·수치 나열)로 전환. 수정한 곳:
- 7p SCE 하단 스탯: "비용 안정성 — 3년 약정 동결" → "증감 없음 사유 — 서버 수량 변동 없음"
- 3p Executive Summary 제목: "성장 비용을 라이선스 최적화로 상쇄했습니다" → "EA 증가분이 기타 라이선스 절감으로 상쇄됩니다" (능동 성과 서술 → 수동 사실 서술)
- 3p 핵심 메시지 3번째 항목: "총 증가율을 +3.9%로 방어" → "총 증가율은 +3.9%입니다"
- 4p 제목: "세 갈래 원칙으로 총소유비용을 관리합니다" → "세 갈래 원칙으로 구성됩니다"
- 5p 제목: "사용자 증가와 비용 절감이 균형을 이룹니다"(4개 별도 법인의 우연한 합산을 마치 의도된 균형처럼 서술) → "회사별 증감률은 -39.8%~+33.7%로 상이합니다" (사실 나열)
- 9p 쏘시오 제목: "~을 절감합니다" → "~이 감소합니다" (수동태)
- 10p 에스티 제목·노트: "~로 상쇄했습니다/낮췄습니다" → "~으로 상당 부분 상쇄됩니다/상쇄되어 +4.3%입니다" (수동태)
- 실사용 기반 실제 최적화(Copilot 조정, Easy Tree 종료 등 벤더가 실제로 수행/제안한 조치)에 대한 "절감합니다" 표현은 실제 조치가 있었으므로 유지 — "아무 일도 없었는데 성과로 포장"한 경우(SCE)와 "실제 조치로 비용을 줄인" 경우(기타 라이선스)를 구분해 후자만 능동태 유지
- 원본 데이터에 명시된 인과 설명("사업 확장에 따른 인력 확충" 등)은 벤더의 자체 평가가 아니라 고객이 제공한 사유이므로 유지
- 제목 축약 과정에서 3p 제목이 2줄로 밀려 밑줄과 겹치는 레이아웃 문제 발견 → 문구를 더 간결화해 해결
