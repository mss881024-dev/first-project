# 킥오프 회의록 — 동아그룹 4개사 Microsoft EA 갱신 제안서 작성 프로젝트

| 항목 | 내용 |
|------|------|
| 일시 | 2026-07-09 |
| 안건 | Microsoft EA(Enterprise Agreement) 3년 차 갱신 제안서 작성 착수 |
| 대상 고객 | 동아쏘시오홀딩스㈜, 동아에스티㈜, 동아제약㈜, 에스티젠바이오㈜ |
| 계약기간 | 2026.02.06 ~ 2028.02.05 (3년 차 갱신) |
| 산출물 | PPT 기반 제안서 1부 (회사별 페이지 + 4사 요약 비교표 포함) |

## 1. 참석 인력 (오케스트라 편성)

| 역할 | 담당 범위 |
|------|-----------|
| PM / 오케스트레이터 | 전체 일정·품질 총괄, 요구사항 관리, 최종 검수 |
| 라이선스 스페셜리스트 | EA 계약 구조(Renewal/True-up) 설명, 단가 체계, 계약 조건 정리 |
| 재무 분석 담당 | 25Y→26Y 금액 검증, 증감 요인 분석, 비교표 산출 |
| 문서 디자이너 | PPT 레이아웃·톤앤매너 설계 (공식 비즈니스 문서 톤) |
| QA | 수치 교차 검증, 표기 일관성 점검 |

## 2. 요구사항 확인 (고객 요청사항)

1. 회사별 별도 제안 페이지 구성 (4개사)
2. 25Y → 26Y 비용 변동 사유를 명확히 설명
3. True-up 증가가 큰 회사(에스티젠바이오, 동아에스티)는 **사업 확장 효과 강조**
4. 전문적이고 공식적인 비즈니스 문서 톤
5. 주요 4사 요약 비교표 포함

## 3. 재무 데이터 검증 결과 (재무 분석 담당 보고)

- 단가 기준(부가세 별도): Renewal 390,600원/명, True-up 457,800원/명
- 검증: 전 항목 단가 × 수량 계산치와 제시 금액 일치 확인 완료. 단,
  - **검증 노트 1**: 동아제약 26Y True-up 제시금액 57,988,000원은 단순 계산치
    (133명 × 457,800원 = 60,887,400원)와 2,899,400원 차이. 도입 시점별
    일할(pro-rata) 정산분으로 판단, **고객 제시 금액을 그대로 적용**하기로 결정.
  - **검증 노트 2**: 각사 소계의 EA 수량(예: 동아에스티 1,249EA)은 과년도 누적
    True-up 포함 수치로, 제시 기준을 그대로 사용.
- 4사 합계: 25Y 934,197,600원 → 26Y 1,045,874,200원 (**+12%**, 증가액 111,676,600원)
- 핵심 메시지: **Renewal 단가·금액은 전사 동결(0%)**, 증가분은 전액 True-up
  (임직원 증가·사업 확장)에 기인 → "비용 인상이 아닌 사용 규모 확대"로 포지셔닝

## 4. 제안서 목차 합의 (문서 디자이너 제안, 전원 합의)

1. 표지 — 계약기간·대상 4사 명기
2. 목차
3. 제안 개요 (Executive Summary)
4. EA 계약 구조 및 단가 기준
5. 주요 4사 요약 비교표
6. 동아쏘시오홀딩스㈜ — 전년 동결(0%)
7. 동아에스티㈜ — True-up 168명, 사업 확장 효과 강조
8. 동아제약㈜ — True-up 22명, +2.6%
9. 에스티젠바이오㈜ — True-up 214명 대폭 추가, 사업 확장 효과 최대 강조
10. 증감 요인 분석 — 증가분 100% True-up 기인
11. 계약 조건 및 향후 일정
12. 맺음말

## 5. 톤앤매너 결정

- 16:9 와이드, 네이비/블루 기반 공식 비즈니스 톤, 맑은 고딕
- 증가 수치는 부정적 표현 대신 "사업 성장 반영"으로 서술
- 금액은 원 단위 콤마 표기, 부가세 별도 명기
