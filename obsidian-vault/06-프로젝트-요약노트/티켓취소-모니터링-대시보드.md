# BigBang 2026 콘서트 취소표 모니터링 대시보드

원본 브랜치: `claude/ticket-cancellation-dashboard-l8uz9h` (전체 소스코드는 이 브랜치에 보존됨, 이 노트는 요약임)

## 개요
- 사용자가 직접 붙여넣은 카카오톡 텍스트 또는 업로드한 이미지에서 취소표 정보를 파싱해 대시보드로 보여주는 개인용 모니터링 도구
- **명시적으로 하지 않는 것**: 예매 사이트 자동화, 카톡 자동 수집, 취소 발생 시간 예측 — 순수 수동 입력 기반

## 기술 스택
- **백엔드**: FastAPI + SQLite (`ticket_dashboard/server.py`)
- **AI 파싱**: Anthropic API로 비정형 텍스트/이미지에서 좌석 정보 추출
- **배포**: Railway (`railway.json`, NIXPACKS 빌더, `uvicorn server:app`)
- **의존성**: fastapi 0.115.6, uvicorn 0.32.1, anthropic 0.40.0, python-multipart, aiosqlite

## 데이터 모델 (SQLite)
- `tickets` 테이블: id, section(구역), seat(좌석), concert_date, status, report_count, raw_text, first_seen, last_updated
- `review_queue` 테이블: 파싱 실패/애매한 항목을 사람이 검토하도록 보류

## API 엔드포인트
| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/` | 대시보드 HTML |
| POST | `/api/parse-text` | 텍스트 붙여넣기 → AI 파싱 → DB 저장 |
| POST | `/api/parse-image` | 이미지 업로드 → AI 파싱 → DB 저장 |
| GET | `/api/tickets` | 전체 티켓 목록 조회 |
| DELETE | `/api/tickets/{ticket_id}` | 티켓 삭제 |
| GET | `/api/review` | 검토 대기열 조회 |
| DELETE | `/api/review/{item_id}` | 검토 항목 기각 |
| GET | `/api/stats` | 통계 |

## 실행 방법
```bash
pip install -r ticket_dashboard/requirements.txt
cd ticket_dashboard && uvicorn server:app --host 0.0.0.0 --port $PORT
```
(Railway 배포 시 `railway.json`의 buildCommand/startCommand 그대로 사용)
