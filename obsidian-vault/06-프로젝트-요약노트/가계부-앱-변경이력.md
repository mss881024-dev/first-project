# 가계부 앱 — 메인 프로젝트 변경 이력

레포 루트의 `app.js` / `index.html` / `style.css`로 구성된 메인 웹앱은 **개인 가계부(household ledger)** 앱입니다. `claude/quirky-cori-4yjkn9` 브랜치에서 대대적으로 기능이 확장되었습니다(app.js +361줄, index.html +19줄).

## 앱 개요
- 제목: "가계부"
- 계좌 탭 2종: **공금통장**(gongeum), **자동차마통**(car, 자동차 마이너스통장)
- 월별 네비게이션(이전/다음 달), 월간 요약 바(누적 잔액 등)
- 데이터 저장: `localStorage` (`fintrack_gongeum`, `fintrack_car` 키)
- 거래 추가/삭제(실행취소 타이머 포함, `pendingDelete` + `undoTimer` 패턴)

## 원본 코드 위치
전체 소스는 `claude/quirky-cori-4yjkn9` 브랜치의 `app.js`, `index.html`, `style.css`에 보존되어 있습니다. 이 노트는 요약이며 전체 코드는 옮기지 않았습니다.
