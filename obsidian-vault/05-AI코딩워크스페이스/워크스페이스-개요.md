## 생략된 내용 — Agency Agents 라이브러리
이 브랜치의 `.claude/agents/` 폴더에는 [The Agency](https://github.com/msitarzewski/agency-agents) 오픈소스 프로젝트에서 가져온 **232개의 범용 Claude Code 서브에이전트 정의 파일**(마케팅·세일즈·엔지니어링·게임 개발 등 각종 직무별 페르소나)이 포함되어 있었습니다. 이는 사용자가 직접 작성한 콘텐츠가 아니라 외부에서 설치한 보일러플레이트 라이브러리이므로, 볼트 용량을 고려해 이 옵시디언 vault에는 **옮기지 않았습니다**. 필요 시 원본 브랜치(`claude/peaceful-ramanujan-fv3p5d`)의 `.claude/agents/` 또는 위 GitHub 저장소에서 확인 가능합니다.
