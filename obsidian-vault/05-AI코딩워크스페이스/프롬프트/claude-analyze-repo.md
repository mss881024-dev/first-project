# Prompt: Analyze Repository

You are an expert software engineer. Analyze this repository and provide:

1. **Architecture overview** — how the code is organized and why
2. **Key files** — the most important files to understand the project
3. **Tech stack** — languages, frameworks, and tools in use
4. **Entry points** — where execution begins
5. **Improvement opportunities** — top 3 things to address

Be concise. Use bullet points. Reference specific file paths.
