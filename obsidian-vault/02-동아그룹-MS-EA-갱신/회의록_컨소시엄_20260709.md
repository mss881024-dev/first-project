# 컨소시엄 회의록 — 동아그룹 4개사 Microsoft EA·SCE 갱신 제안서 리뉴얼

| 항목 | 내용 |
|------|------|
| 일시 | 2026-07-09 (2차 회의 이후 3~7차 개정 누적 기록) |
| 안건 | ① 기존 제안서 디자인 전면 개편 ② SCE(서버) 라이선스 데이터 추가 반영 ③ 계약기간 변경 |
| 배경 | 고객 피드백: 기존 디자인 불만족, SCE 라이선스 누락, 계약기간 2026.03.31~2028.04.01로 변경(이후 재정정) |

이전 회의: [[회의록_킥오프_20260709]]

## 1. 컨소시엄 편성 (실제 서브에이전트 소환)
| 역할 | 수행 내용 |
|------|-----------|
| 오케스트라 PM (본 세션) | 총괄, 데이터 검증, 디자인 방향 결정, 최종 구현·QA |
| 디자이너 A (에이전트) | "모던 클린" 시안 — 기존 디자인 문제점 5개 + 신규 스펙 제안 |
| 디자이너 B (에이전트) | "이그제큐티브/컨설팅 리포트" 시안 — 액션 타이틀 체계 제안 |
| PPT 구성 설계 (에이전트) | 15장 스토리보드 — 깔때기 구조(결론 선행 → 요약 → 상세 → 분석) |

## 2. 디자이너 의견 수렴 결과
**공통 지적**
- 꽉 찬 네이비 헤더바·전면 네이비 표지가 무겁고 올드함 (90년대 SI 제안서 인상)
- 네이비 채움 표 헤더 + 전체 세로선이 숫자 비교를 방해
- 오렌지/컬러 강조 남발로 시선 우선순위 붕괴
- 박스 중첩 과다, 여백 부족

- **디자이너 A(모던 클린)**: 흰 배경 + 가는 라인 + 오렌지 1포인트, 라운드 KPI 카드, 화이트 표지
- **디자이너 B(컨설팅 리포트)**: 액션 타이틀(제목=결론 한 문장), 헤어라인 표, 빅넘버 스탯 밴드, 페이지 트래커, 모노톤+틸 1색

## 3. PM 결정 사항 — 하이브리드 채택
1. **레이아웃 문법**: 네이비 면 채움 전면 폐기, 흰 배경 + 헤어라인 + 여백
2. **팔레트**: 디자이너 A안 — 네이비 잉크(#1B2A4A) + 오렌지(#E86C1A) 단일 액센트 (틸 전환은 브랜드 연속성 저하로 기각)
3. **타이틀 체계**: 디자이너 B안 — 전 슬라이드 액션 타이틀
4. **표 스타일**: 세로선·채움 제거, 상단 1.5pt/헤더 하단 0.75pt 네이비 라인 + 0.5pt 헤어라인, 합계행만 옅은 채움
5. **숫자 강조**: 빅넘버 스탯 밴드 (슬라이드당 최대 3개, 강조색 슬라이드당 1~2곳 원칙)
6. **구성**: 설계 에이전트 15장 안 → 14장 압축 (계약구조+갱신전략 통합, 워터폴 차트 → 표+스탯 대체)

## 4. 신규 데이터 검증 (2차)
- SCE 5개 품목 × 4사 소계, EA+SCE 회사별 합계, 전체 총계 전 항목 검산 **일치**
- 에스티젠바이오 SCE 5개 품목 합산 시 28,834,201원 vs 제시 소계 28,834,200원 — **1원 차이**(원 단위 절사 추정). 4사 SCE 합계·전체 총계도 동일. → **고객 제시 금액을 기준으로 표기**
- 계약기간 2026.03.31~2028.04.01로 전 슬라이드 갱신(이후 재정정). 이전 버전 단가(390,600원 등)는 신규 요청 미포함으로 제외.

## 5. 산출물 구성 (14장, 2차 기준)
표지 → 목차 → ①제안 개요 → ②계약 구조·갱신 원칙 → ③4사 총계 비교 → ④EA 요약 → ⑤SCE 요약(전 품목 동결 매트릭스) → ⑥~⑨회사별 상세 → ⑩증감 요인 분석 → ⑪계약 조건·일정 → 맺음말

## 6. 기타 라이선스 추가 반영 (3차, v3)
- 추가 데이터: 기타 라이선스(Copilot·Teams Pro·Easy Tree) 4사분 수신 → 15페이지로 재구성
- 스토리 변경: 총계 기준 +9.3% → **+3.9%** (True-up +111.7백만 원을 기타 최적화 -62.8백만 원으로 상쇄)
- 신규 슬라이드: 기타 라이선스 요약(-88%), 회사별 페이지에 기타 표 추가, 증감 분석에 절감 구성 반영
- **검증 노트(v3)**: 동아쏘시오홀딩스 전체계(70,779,400/42,631,000원)가 구성 항목 합산보다 각 42원 작음(단수 조정 추정, 원본엔 조정행 없음) → 제시 금액 기준 표기. 원본 하단 "계약 정보: 2024.03.31~2027.04.01"이 상단 표기와 불일치 → 당시 상단 기준 적용(이후 재정정). 그 외 전 항목 검산 일치.

## 7. 전수 계수 검증 (4차)
사용자 요청으로 전체 수치 재검산(EA/SCE/기타 소계, 회사별 전체계, 4사 총계, 증감률, 스크립트 하드코딩 금액 전부).

- **결과**: 금액·증감률 전 항목 일치. 기존 2건(쏘시오 단수 42원차, 계약기간 표기 불일치) 재확인, 4사 합산 단수조정(-2,302/-4,902)이 쏘시오(-42/-42)+에스티(-2,260/-4,860)의 정확한 합임을 추가 확인 — 표기 오류 아님.
- **신규 발견·수정**: PPT 08·13번 슬라이드의 "Copilot 105→15 Copy" 서술이 원본 미제공 수치(쏘시오 Copy 수 추정치)를 포함 → **"3사 82→15 Copy 재산정, 쏘시오는 갱신 종료"로 수정**.

## 8. 문구 리스크 검토 (5차)
사용자 지적: "에스티젠바이오 +33.7% — 사업 확장(+130EA)이 만든 성장의 지표입니다"라는 제목이 비용 증가를 벤더가 "성장의 지표"로 규정하는 것처럼 읽혀 리스크 있음.

동일 패턴 전체 스캔, 3곳 수정:
- 에스티젠바이오 상세 페이지: "성장의 지표입니다" → "증가분은 전액 True-up 130EA(사용자 순증)에서 발생했습니다"
- 4사 총계 비교: "성장 투자(에스티젠·에스티)" → "사용자 증가(에스티젠·에스티)"
- 기타 라이선스 요약 스탯: "성장 재원" → "56% 상쇄"

고객이 제공한 사유(사업 확장 반영 등)는 유지, 벤더가 독자적으로 "좋은 신호"라 평가하는 표현만 제거.

## 9. 계약기간 정정 (6차, 최종 확정)
사용자 확인: 계약기간은 **2024.03.31 ~ 2027.04.01**이 맞음 (v3 하단 "계약 정보"가 정확했고 상단 표기가 오기재였음 — 4차 검증에서 반대로 추정했던 것을 정정).
- 전 슬라이드 계약기간 표기를 2024.03.31~2027.04.01로 일괄 수정
- "3년 차 갱신" 라벨과 일관성 확보(기존 2026→2028 표기는 실제 2년+1일이라 모순이었음, 해소됨)
- STEP 3 "계약 체결(2024.03.31 발효)"는 지난 날짜를 향후 일정으로 표시하는 오류 → **"3년 차(26Y) 갱신 물량 확정"**으로 수정. STEP 4도 "확정분 반영 및 연중 True-up 관리 지원"으로 조정

## 10. 톤 전면 재검토 (7차, 최종)
**계기**: "비용 안정성 — 3년 약정 동결"(서버 수량이 애초에 늘지 않아 자연히 0%인 것을 벤더 성과처럼 표현)이 지적됨. 사용자가 전체 톤에 근본적 문제 제기.

**PM 판단**: 컨설팅식 액션 타이틀 기법을 적용하며 벤더가 고객이 느껴야 할 감정·해석까지 규정하는 표현이 여러 곳에 스며듦 — 내부 결재 근거 자료 성격상 신뢰도 훼손 우려.

**수정 범위: 전체 재검토.** 능동적 성과·해석 표현 → 팩트 서술(수동태·수치 나열)로 전환:
- 7p SCE 하단: "비용 안정성 — 3년 약정 동결" → "증감 없음 사유 — 서버 수량 변동 없음"
- 3p Executive Summary: "성장 비용을 라이선스 최적화로 상쇄했습니다" → "EA 증가분이 기타 라이선스 절감으로 상쇄됩니다"
- 3p 핵심 메시지: "총 증가율을 +3.9%로 방어" → "총 증가율은 +3.9%입니다"
- 4p 제목: "세 갈래 원칙으로 총소유비용을 관리합니다" → "세 갈래 원칙으로 구성됩니다"
- 5p 제목: "사용자 증가와 비용 절감이 균형을 이룹니다" → "회사별 증감률은 -39.8%~+33.7%로 상이합니다"
- 9p 쏘시오: "~을 절감합니다" → "~이 감소합니다"
- 10p 에스티: "~로 상쇄했습니다/낮췄습니다" → "~으로 상당 부분 상쇄됩니다/상쇄되어 +4.3%입니다"
- 실제 조치가 있었던 경우(Copilot 조정, Easy Tree 종료)의 "절감합니다" 능동태는 유지 — "성과 없이 포장한 경우(SCE)"와 "실제 조치(기타 라이선스)"를 구분
- 고객이 제공한 인과 설명("사업 확장에 따른 인력 확충")은 유지
- 제목 축약 과정에서 3p 제목 2줄 겹침 레이아웃 문제 발견 → 문구 간결화로 해결
